# ElasticPanel — Privacy Policy / Gizlilik Politikası

**Last updated / Son güncelleme:** 18 May 2026

---

## English

### Summary
ElasticPanel is a Chrome extension for managing Elasticsearch clusters. **It does not collect, store, transmit or share any personal data.** All data stays locally in the user's own browser.

### Data we collect
**ElasticPanel does not send any user data to the developer or any third party.** The following items are stored **only on the user's own device**, via the `chrome.storage.local` API:

- Elasticsearch cluster connection details manually added by the user (URL, username, API key, alias)
- Language and theme preferences
- Optional query history (kept locally, never transmitted)

None of this data leaves the user's device. The developer has no access to it.

### Network requests
ElasticPanel only sends HTTP/HTTPS requests to the Elasticsearch endpoints **the user manually adds** in the "Connections" screen. These requests:

- Go only to the user's own Elasticsearch servers
- **Are not** sent to the developer's servers or any analytics/telemetry service
- Are not routed through any third-party service

### Data we do NOT collect
ElasticPanel **does not collect any of the following**:

- Personally identifiable information (name, email, address, etc.)
- Health information
- Financial or payment information
- Web browsing history
- Location data
- User activity (clicks, mouse movement, keystrokes, etc.)
- Content of other websites
- Personal communications

### Permissions
The permissions declared on the Chrome Web Store (`storage`, `tabs`, `activeTab`, `sidePanel`, `host_permissions`) are used exclusively for the extension's core purpose: Elasticsearch cluster management. No permission is used for data collection.

### Third-party services
ElasticPanel uses no third-party analytics, advertising or tracking services. No external JavaScript or remote code is loaded at runtime.

### Data security
Connection details (including API keys) are stored using Chrome's local storage mechanism. The security of this data is bound to the security of the user's device and Chrome profile.

### Changes
Changes to this policy will be published on this page.

## Türkçe

### Özet
ElasticPanel, Chrome tarayıcısı üzerinden Elasticsearch cluster'larını yönetmek için tasarlanmış bir uzantıdır. **Hiçbir kişisel veriyi toplamaz, saklamaz veya üçüncü taraflarla paylaşmaz.** Tüm veriler yalnızca kullanıcının kendi tarayıcısında, yerel olarak tutulur.

### Toplanan Veriler
ElasticPanel **hiçbir kullanıcı verisini geliştiriciye veya üçüncü taraflara göndermez**. Aşağıdakiler **yalnızca kullanıcının kendi cihazında**, `chrome.storage.local` API'si aracılığıyla yerel olarak saklanır:

- Kullanıcının manuel olarak eklediği Elasticsearch cluster bağlantı bilgileri (URL, kullanıcı adı, API key, takma ad)
- Dil ve tema tercihleri
- Sorgu geçmişi (yalnızca kullanıcının kendi cihazında, isteğe bağlı)

Bu veriler kullanıcının cihazından dışarı çıkmaz. Geliştiricinin bu verilere erişimi yoktur.

### Ağ İstekleri
ElasticPanel, yalnızca kullanıcının "Bağlantılar" ekranından **kendi manuel olarak eklediği** Elasticsearch endpoint'lerine HTTP/HTTPS isteği gönderir. Bu istekler:

- Yalnızca kullanıcının kendi Elasticsearch sunucularına gider
- Geliştiricinin sunucularına veya herhangi bir analitik/telemetri servisine **gönderilmez**
- Üçüncü taraf servislere yönlendirilmez

### Toplanmayan Veriler
ElasticPanel aşağıdaki verilerin **hiçbirini toplamaz**:

- Kimliği tanımlayabilecek bilgiler (ad, e-posta, adres vb.)
- Sağlık bilgileri
- Finansal bilgiler veya ödeme bilgileri
- Web tarama geçmişi
- Konum bilgisi
- Kullanıcı etkinliği (tıklama, fare hareketi, tuş vuruşu vb.)
- Diğer web sitelerinin içeriği
- Kişisel iletişimler

### İzinler
Chrome Web Store'da beyan edilen izinler (`storage`, `tabs`, `activeTab`, `sidePanel`, `host_permissions`) yalnızca eklentinin temel işlevini (Elasticsearch cluster yönetimi) yerine getirmek için kullanılır. Hiçbir izin kullanıcı verisi toplamak amacıyla kullanılmaz.

### Üçüncü Taraf Servisler
ElasticPanel hiçbir üçüncü taraf analitik, reklam veya izleme servisi kullanmaz. Çalışma zamanında harici JavaScript veya uzak kod yüklenmez.

### Veri Güvenliği
Bağlantı bilgileri (API key dahil) Chrome'un yerel depolama mekanizmasında saklanır. Bu verilerin güvenliği, kullanıcının cihazının ve Chrome profilinin güvenliği ile sınırlıdır.
